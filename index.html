    Apps Script 웹 앱 주소

    학생에게 보낼 링크

    이 링크로 들어온 학생은 시트가 자동으로 연결돼요. 학생은 따로 입력할 필요가 없어요.

    처음 한 번만: 연결 방법

    1. 구글 드라이브에서 새 구글 시트를 만들어요. (예: "2학년 말하기 리허설")
    2. 시트 메뉴 확장 프로그램 → Apps Script를 열고, 원래 있던 코드를 지운 뒤 아래 코드를 전부 붙여넣고 저장해요.
    3. (AI 코치를 쓸 때) Google AI Studio에서 API 키를 무료로 만들어요. Apps Script 왼쪽 ⚙︎ 프로젝트 설정 → 스크립트 속성 → 속성 추가에서 이름 GEMINI_API_KEY, 값에 키를 넣고 저장해요.
    4. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택 → 실행: 나, 액세스 권한: 모든 사용자 → 배포. (처음엔 권한 허용 창이 떠요. "고급 → 안전하지 않음으로 이동"을 눌러 허용해요.)
    5. 나온 웹 앱 URL을 위 칸에 붙여넣고 저장 & 연결 테스트를 누르면 끝! 시트에 "리허설기록", "질문기록", "발음연습" 탭이 자동으로 생겨요.

    코드를 고친 뒤에는 배포 → 배포 관리 → ✏︎ → 버전: 새 버전으로 다시 배포해야 반영돼요.
